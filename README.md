# 🧮 Kinchi Compute

> *Your modern companion for quick calculations.*

Kinchi Compute is a sleek, responsive, and lightweight **Progressive Web App (PWA)** built with vanilla HTML, CSS, and JavaScript. Designed with a modern glassmorphism aesthetic, dynamic theme switching, and seamless history tracking.

[![Live Demo](https://img.shields.io/badge/Live-Demo%20%F0%9F%9A%80-brightgreen)](https://t3nch11.github.io/kinchi-compute/)

## ✨ Features

- 🌙 **Dynamic Light/Dark Themes:** Responsive theme toggle anchored perfectly for both desktop and mobile layouts.
- 📱 **Progressive Web App (PWA):** Fully installable on iOS and Android devices with offline support via Service Workers.
- 🕒 **Calculation History:**
  - Save and view past operations.
  - Pin important calculations.
  - Search history logs in real-time.
  - Export history to **JSON** or **CSV**.
- 💡 **User Hints & Tooltips:** Interactive popups for quick user onboarding and quick-action shortcuts (e.g., Hold `AC` to clear all).
- 📋 **One-Tap Clipboard Copy:** Easily copy result outputs to your clipboard.
- 📐 **Responsive Design:** Optimized layout scaling across mobile screens, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid)
- **Scripting:** JavaScript (Vanilla ES6+)
- **Storage & PWA:** Web Storage API (LocalStorage), Web App Manifest, Service Workers
- **Hosting:** GitHub Pages
